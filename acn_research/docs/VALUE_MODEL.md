# 信息价值实验的数学对象

## 场景与动作

六个会话在起点已连接，请求和声明离开时间此时披露且准确。每周期 5 分钟、208V；动作以 6A 为一单位，允许 0–5 单位；公共 feeder 容量为 6、10 或 30 单位。一个单位对应 0.104 kWh。需求是整数单位，用户离开即终止。外生二值可充状态 a(i,t) 决定实际交付 `min(pilot, remaining) * a`；动作改变必须重新计算电流。

这是受 ACN 实际离散控制和低流恢复现象启发的压力测试，不是从 office 日志识别出的电池模型。所有模拟暂停最终恢复，故偏向给恢复预测创造机会；真实审计中多数首告警没有观察到恢复。未建模三相网络、SOC/taper、费率、切换成本、动作诱发的暂停、新到达、请求误差。不能外推到真实部署。

## 完全信息上界

离线问题最大化 sum x(i,t)，限制 sum_t x(i,t) <= demand(i)，sum_i x(i,t) <= feeder，0 <= x(i,t) <= 5*a(i,t)，离开后上界为零。它等价于时间节点到会话节点的容量网络流（network flow）：源到时间容量为 feeder，时间到会话边容量为 5*a，会话到汇容量为 demand。整数容量保证整数最优流；所以这里 LP 的整数解属于同一个离散动作空间，而非连续松弛。

代码核查每次求解的整数性、能量和约束，并在 16 个微型可充状态上与枚举所有动作比较。对总能量目标，离线最优减任意基线是该明确模型里额外信息可能改进的上界；离线信息包含未来暂停开始时刻，比“只知道恢复”更丰富。

## 信息划分

- 真实反馈组：修正后的原生 AdaCharge、指令感知 EDF/LLF、因果 MPC，只看过去动作与实际响应。没有下发电流不当成车辆不能取电。探测成功后 EDF/LLF/MPC 立即恢复额定上限，形成有竞争力的常规对照。
- 当前状态组（current-state oracle）：同一 MPC 在动作前获知当前能否取电。它有实际传感器可能无法提供的信息，所以相对真实反馈的收益不归给提前预测。
- 提前恢复组：在当前状态组基础上增加提前 5 分钟、15 分钟或暂停期间全程精确恢复时刻。未来暂停开始时刻仍不可见。保证会发通知的 oracle 中，“还没收到通知”也是未来信息，已显式计入。
- 完全信息离线组：知道所有可充状态，用于同模型上界。

所有 MPC 用同一网络流优化器和总能量目标；以总扰动不足 0.25 单位的确定性早充/截止时间偏好打破平局，不改变整数总能量最优值。只看原生作者算法与 oracle 的差异不能证明新机制，因此同时加入简单强基线。

## 开发与评估隔离

开发种子 100–109，评估种子 200–219；三种容量分别报告，无暂停为负对照。开发阶段的当前状态 MPC 在 2/4/6/8 周期暂停持续时间假设下总交付相同，按顺序选择 2；所有评估 MPC 共用它。按开发平均交付选出的固定因果对照是 EDF，不能在每个评估场景事后择优。选择结果及协议 SHA256 在 value_selection.json，评估前先提交。

开发结果中原生量化 MPC 仍弱于简单 EDF；这要求在解释中保留控制实现差异。没有训练新的恢复预测器，也不将 oracle 的精确通知当作可实现的预测精度。
