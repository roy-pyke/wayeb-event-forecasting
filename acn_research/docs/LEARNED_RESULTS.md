# R1：真实预测未复现完美通知收益

2026-10-23。结论：**目前没有证据支持“预测减少无效探测并及时恢复额度”是一个有效的新机制**。真实模型已训练、冻结并在独立场站执行；主探测指标打平强基线，拥挤多车压力测试略差。保留全部负结果，不以完美通知替代实测预测。

## 数据与目标

共核验3874个录制、21,506,342行：Office1474，Caltech California Garage 01及JPL Arroyo Garage 01各按文件哈希预选1200。每个下载的Git blob与固定作者仓库匹配。原始数据、逐会话关联和模型在忽略目录，Git只存代码、协议及汇总。

主目标是在低电流告警后，正pilot支持下确认>=6A持续60秒。遇到缺测/撤销pilot即删失；拔枪是竞争结局。表中的正例是60分钟以内；不能与旧206个任意时刻>0.5A回升直接等同。

|数据部分|支持条件合格告警|完整60分钟结局*|持续恢复|其中告警时有未满足请求且在声明截止前恢复|
|---|---:|---:|---:|---:|
|Office训练|555|548|27|0|
|Office开发|130|128|9|0|
|Office时间留出|149|139|35|18|
|Caltech外部|384|347|9|4|
|JPL外部|73|72|2|0|

*包含提前恢复及提前拔枪这种已判定结局，并非每个文件都有完整60分钟的持续录制。Office另4个跨边界告警被purge。Caltech有277个首告警、JPL有897个首告警不满足pilot支持条件，不当作负例；JPL有效覆盖仅73/1200。两个外部站属于同一ACN平台，独立场站验证不等于跨供应商/跨产业验证。JPL仅2个正例，不足以有力检验泛化。

## 冻结预测器及真实误差

仅Office训练集拟合；开发集平均多时域Brier选择GBDT，模型SHA256与阈值在外部评估前提交2381103。比较经验CDF、elapsed-only逻辑回归、全特征逻辑回归、GBDT。所有模型保留，而不是测试后挑选赢家。

|测试组|15分钟正例/可判定数|GBDT平均预测概率|GBDT Brier@60|经验CDF Brier@60|
|---|---:|---:|---:|---:|
|Office留出|14/146|0.2964%|0.24010|0.22941|
|Caltech|4/368|0.3604%|0.02514|0.02581|
|JPL|0/73|0.3323%|0.02776|0.02747|

Office训练15分钟只有1/553正例，开发0/128，时间留出却14/146，发生明显分布变化（distribution shift）。以预定0.5阈值报告混淆矩阵时，三个测试组均没有报警，18个真实15分钟正例全部漏报；“0误报”绝不表示模型好。控制策略使用连续概率及失败反馈，不直接使用这个0.5分类阈值。

训练中无可用声明请求，测试中请求可用性上升，因此本轮不能声称学会了真实剩余需求与截止时间的作用。高维模型也没有优于简单elapsed-only模型的普遍证据。完整AP、log loss、ECE、各时域分数及按日bootstrap见`reports/r1/evaluation.json`。

## 真实误差进入探测策略

离散5分钟、最大等待20分钟。主代价为失败探测次数+发现延迟槽数；固定间隔/退避均在开发集选定每20分钟。预测DP、同CDF概率阈值策略及经验CDF-DP接收相同信息。

在558个可完整判定的留出告警（Office139、Caltech347、JPL72）上，GBDT-DP与选定基线**逐个样本主代价完全相同**，平均增益0。恢复样本的量化发现延迟分别10.57、9.44、7.50分钟；这是确认恢复后再发现的延迟，不是提前量。5分钟量化还会增加不足5分钟的实际等待。单会话20分钟等待上限在共享容量阻止探测时不保证成立。

人为将预测提前/推迟10分钟，主代价仍打平；把CDF抬高0.2时Caltech/JPL主代价分别增加0.00576/0.01389。延迟成本权重提高到4时，抬高概率使Office代价下降0.7842，却使Caltech/JPL增加0.8213/0.8056。这是明确标注的误差压力测试，不能挑Office改善就宣称校准方案有效；外部结果方向相反。

## 多车额度闭环

R1-S1协议先于留出预测评估提交2857413。720个配对世界、8640次策略运行：每组3台活动车+3个从真实留出告警抽取的暂停车，显式假设恢复后保持6A或30A可充能力，使用公开给控制器的合成需求/截止时间。每次新pilot都重新计算实际交付。与真实已识别响应或真实用户电量收益不同。

下表为恢复上限30A假设下，学习DP相对每20分钟探测的平均交付变化，单位kWh/六车/一小时：

|来源场站|36A feeder|60A feeder|180A feeder|
|---|---:|---:|---:|
|Office留出|-0.0156|-0.0026|0|
|Caltech|-0.0130|0|0|
|JPL|-0.0104|0|0|

6A恢复上限下36A的负值相同，60A全部打平。没有学习DP正增益世界。全部180A策略达到离线网络流上界；能量、档位、容量和截止约束检查全部通过。重新采样的40种子区间只描述这批有限源样本下的仿真变动，不是独立真实场站总体置信区间。

完整恢复/不恢复oracle在30A恢复假设下36A平均增益为Office+0.1898、Caltech+0.1976、JPL+0.1976。这一oracle连“永不恢复”也知道，能停止所有无效探测，比P2有限提前通知更强；不能将它的收益归给已训练模型，也不是任意策略的信息价值上界。6A情况下oracle有少数负世界，说明固定EDF还会因恢复动作挤占别的车辆。

## 已定位的失败原因

1. **目标变化有实质影响。** 很多0.5A回升不是持续6A恢复；可用恢复事件远少于原始回升计数。合格恢复的确认电流中位数Office7.7A、Caltech7.9A、JPL7.55A，没有一个达到30A，故30A只是压力假设。
2. **信息/分布不足。** 早期训练几乎没有快速持续恢复或已声明需求，未来时段的恢复比例和请求覆盖都不同。模型普遍低估快速恢复；不能通过在测试集上反复选阈值修复。
3. **控制目标不匹配。** 单车DP优化失败次数和固定延迟权重，没有把每个时刻被挤占车辆的机会成本纳入状态。Office合成种子703中三台暂停车都不恢复，DP在槽8多给一台暂停车6A，挤掉活动车6A，损失0.104kWh；经验CDF-DP同样损失，故不能全归咎于复杂模型误差。
4. **最长等待的结构限制。** 当恢复概率很低，20分钟上限令DP退化为每20分钟探测；这本身无法比已经选择的每20分钟基线减少永不恢复样本的探测。放宽上限会增加迟报风险，不能仅以少探测判胜。
5. **机制新颖性不足。** 目前实现是标准有限时域有代价观测DP，近邻工作已联合预测、探测和调度。没有证明其跨场站收益，也没有区别于既有主动感知理论的新结论。

## 当前判断

不能把本轮作为“新机制有效”的论文证据。它支持的较窄结论是：在ACN这种部分可观测控制数据里，完美通知的条件性潜力并不自动转化为学习预测器的收益；支持条件、可用请求、稀少正例、时间漂移和控制目标错配足以使收益消失。后续若继续，关键是具备动作支持的状态/请求数据与真正联合机会成本的机制，而不是在这三个测试组上继续调参或更换“好看”的指标。

25项语义测试已通过；源码、选择、数据清单散列、完整正负数值及复现命令均留存。用户原始请求和逐会话敏感数据未推送。
