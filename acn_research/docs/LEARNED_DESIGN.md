# 真实预测器与有代价探测：R1 设计记录

2026-10-23。这是在 P2 完美通知（perfect notice）实验之后冻结的新实验，不覆盖原结果。协议：`configs/LEARNED_PROTOCOL_R1.json`。

## 为什么改目标

P2 的小幅条件性收益依赖准确恢复时间；原首告警审计把 >0.5A 的回升算作恢复，但小电流或短暂尖峰不证明车辆能持续消耗恢复后的额度。R1 主目标改为 **>=6A 持续60秒，且有>=6A pilot支持**，使用确认时刻，避免将未来60秒的持续性假装成当时已知。0.5A 回升只作次要描述。

只预测在告警前真实可见的前缀（prefix）。预测对象是历史控制策略下、正 pilot 支持窗口中的恢复分布；它不是已识别的反事实电池模型。遇到撤销 pilot、缺测或采样缺口即删失（censoring），拔枪作为竞争结局（competing event）。所有会话保留审计分母，不能只抽后来恢复的车辆。

## 机制及新颖性边界

候选机制使用恢复时间累计分布（CDF），在每次失败探测后做条件更新，并比较探测占用的机会成本与延迟恢复的损失；最长等待20分钟，且空余容量允许免费探测。有限时域动态规划（dynamic programming, DP）计算何时再探测；同一预测器还供给简单概率阈值策略，以区分预测质量和控制机制。

这是一项可审查的实现假设，**目前不声称算法新颖**。状态信念、探测代价、动态安排观测、错误预测回退在既有主动感知（active sensing）及学习增强调度（learning-augmented scheduling）中均有先例。真正需要验证的是有限离散 pilot、共享容量、声明需求/截止时间及错误恢复预测的组合是否产生新的结构性结论；将这些部件拼在一起不是证明。

## 开源应用对应

[evcc issue #28652](https://github.com/evcc-io/evcc/issues/28652) 的用户报告描述睡眠状态错误反复出现、充电计划未执行，提出冷却/重试限制。它支持“唤醒/失败重试/状态恢复”是现实工程问题，但 issue 的原因分析仍是报告者陈述，不能当已验证缺陷或实验数据。另一个 [discussion #32439](https://github.com/evcc-io/evcc/discussions/32439) 最后指出禁用了 wake-up calls，不能截取前面的错误日志说一定是预测不足。ACN 的正 pilot 下不取电，与通过厂商 API 主动唤醒有不同因果机制，不能混称独立场景实验证据。

## 数据划分与独立场景

Office 全1474个录制按起始日切分60/20/20，跨边界录制排除；前期已经看过总体审计，明确承认它不是从未接触过的数据。只用训练部分拟合，开发部分选预测器和固定基线。Caltech California Garage 01 与 JPL Arroyo Garage 01 各固定抽1200个文件，按路径SHA256选择，读取内容前决定；完全不用于调参。这是独立场站（site transfer），不是独立产业或不同供应商平台。

特征不含身份和最终结果，声明请求仅按 modifiedAt 截断，缺失保持缺失。训练与测试按每个会话一条告警进行；没有拆同一会话的邻近窗口充当独立样本。按日 bootstrap，报告覆盖率、删失、正例数和少数类问题。不能靠高准确率掩盖“几乎都不会恢复”。

## 预测和效用分开判断

主预测比较：训练经验分布、仅elapsed-time逻辑回归、全特征逻辑回归、梯度提升树（GBDT），均报告 Brier、log loss、平均精度（AP）和校准。每个时域完整可判定样本上的评价是条件性评价，不假设删失独立。

发现实验计算失败探测次数和恢复到发现的延迟，主归一化代价是两者以5分钟为单位相加，并给出两个代价比敏感性。它不等于真实电费或实际交付电量。使用真实留出预测误差；额外人为提前/推迟10分钟或概率+0.2只作压力测试。

如果加入多车闭环，明确保持响应模型假设：从真实告警获取恢复时刻，但恢复后吸收态、未来需求、截止时间与可充上限由实验定义。重新计算每个新 pilot 的实际交付，不能直接把旧电流重复播放为新动作结果。结果只能证实这一模型下的价值，历史日志无法证明干预因果效果。

## 预先列出的失败解释

1. 持续恢复极少：0.5A“回升”混入无服务价值尖峰；原预测任务错误。
2. 经验分布与复杂模型相当：前缀信息不足、样本不足或新场站分布变化；不能靠测试集调参补救。
3. 预测分数更好却控制收益为负：误报浪费额度、迟报错过服务，或基线已足够强。
4. DP与同预测器阈值无差别：机制贡献不足。
5. 只在某一代价比/场站/响应假设有效：保留条件及负结果，不合并成普遍正结果。
6. 新颖性不足：实验可形成可信审计，但不足以自称新算法论文。
