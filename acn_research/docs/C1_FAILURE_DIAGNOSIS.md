# C1 结果与无暂停异常的定位

在已提交协议下完成 120 个留出仿真场景、1080 次策略运行、2410 次原生非空求解，所有动作和能量约束断言通过。C1 原始结果保存在 reports/value_evaluation.csv 和 value_summary.json，后续不覆盖。

提前恢复相对当前状态 MPC 的增量在 36A 和 180A 下为零；60A 下全程精确恢复 oracle 平均 +0.0104 kWh，按种子配对 bootstrap 95% 区间 [-0.0468, 0.0780]。提前 5/15 分钟平均 -0.0156 kWh。这不是稳定的正收益。

但是原生基线在无暂停对照中也少交付约 2 kWh，不能直接把 oracle 相对原生基线的差距归给预测。逐周期检查 no_pause/36A/seed200：原生 pilot 总和连续 20 个周期都是 30A，离线可行解为 36A，仍有未满足需求。

追到作者 `diff_based_reallocation`：它用优化器给出的浮点总和作为 `peak_limit`，并用严格 `new_sum <= peak_limit` 判断最后一次离散递增。一个本应为 36A 的优化解若得到 35.99999999A，就会拒绝总和恰为 36A 的离散动作。`ub` 比较也有同样边界风险。

修正方案不是增大物理容量：只对重分配的浮点 peak/ub 比较加 1e-5 A 数值容差，原独立基础设施约束检查继续生效，全部实际输出仍须通过离散档位和物理容量检查。保存确定性最小反例，固定补丁与散列后重跑开发选择，并使用新的 300–319 种子评估。旧结果保留为发现缺陷的诊断，不作为最终强基线性能。

提前信息可能改变动作却不改变总交付：36A 场景 full recovery oracle 在 14/20 个世界改变了 dispatch，能量增量仍全为零。因此“通知未接入”并非零收益的解释。在 60A 的个别场景出现正负变化，说明有限 MPC 也可能被更多局部未来信息诱导到对尚不可见的未来暂停更差的安排；固定策略 oracle 不是 EVPI 定义。
