# R2 阶段结果与继续修正的依据

已完成网站132个、PlanetLab28个测试窗口，每窗口32槽，四个容量、十个策略。开发集选中的最强普通对照是 independent_two_step，选择在测试控制器执行前提交47710d5。

主容量K=2时，joint_two_step 比该对照分别多70与39个价值单位，即+0.3933%与+1.1607%。窗口配对bootstrap95%区间分别为每窗口[0.0152,1.0833]和[0.25,2.4643]。共享容量充足K=6时没有增益。K=1有更大差别，但不是主门槛，不能事后换主结果。

尚不能据此宣布新机制成立：

1. 去掉前瞻中的观测更新，网站价值反而17886 > 17870；PlanetLab为3377 < 3399，但区间下界恰为0。联合收益不等于信息价值已验证。
2. 独立域故障持续性和主域非常不同。900秒内实际恢复率约0.00561，转移模型却给0.16850；该预测器明显失配。总体Brier被大量持续上线所主导。
3. 全上线负对照中，联合方法相对普通myopic仍有约2.57/2.68价值单位增益，说明队列/截止期调度可以产生表观“预测收益”；相对独立两步策略则分别为-0.288/+0.286。
4. 三条已知上线请求的显式反例：价值[3,2,3]、截止期[3,1,3]、容量1。两步目标选第一条得到两步价值6，高于先做第二条的5；但三步全局应先做即将过期的第二条，总价值8，两步选择最多只得6。扩展前瞻时域需要更强的对照，而不是把两步Bellman公式命名成新算法。
5. 不相交窗口仍可能位于同一长期故障中，普通窗口bootstrap可能低估不确定性；追加按日块聚类敏感性。

据此冻结R2B：增加按全部可见截止期进行有限时域单目的地DP、再通过共享容量拉格朗日价格（Lagrangian price）协调的强对照。它也是已有的规划工具，目的在于排除弱对照导致的小幅正结果。R2原策略和原结果保留，不根据测试集调其参数；R2B作为事后反证审计，不冒充新留出验证。
