# 可复核的结构性结论 / Structural results

这些结论界定模型和机制，不宣称它们是新定理。

## 首次恢复分布不是共享分配的充分统计量

两个目的地，上一槽均不可用；每槽只有一个请求额度，未来只看两个槽。两个队首请求的价值分别4、3，截止期均不早于观察期末。共同的 DOWN→UP 概率是1/2，因此当前可用概率都是1/2；首次恢复时间R在两种模型中严格相同：`P(R<=r)=1-2^(-r)`。

只改变 UP→UP 的持续概率：模型A为0.55，模型B为0.99。未观测目的地下槽的可用概率是 `x=(0.5+p11)/2`。现在先尝试价值4请求，其两槽价值为 `2 + 0.5*(3*x) + 0.5*max(2,3*x)`；先尝试价值3请求则为 `1.5 + 0.5*(4*x) + 0.5*max(1.5,4*x)`。

- A：两动作价值为3.7875与3.6，唯一最优是先尝试价值4请求。
- B：两动作价值为4.235与4.48，唯一最优是先尝试价值3请求。

两个模型连首次恢复CDF都完全一致，却要求不同的共享容量决策。故对这一决策类，首次恢复CDF不能普遍决定最优动作；还需恢复后的持续性/再次中断结构。第二步分配使用第一步自己的响应，不偷看另一个目的地的状态。`mechanism_audit.py` 枚举相同分支验证数值，单元测试用独立完整状态枚举再核对。

这为放弃吸收态恢复目标提供了明确理由。它不是首个部分可观测马尔可夫决策问题：早期[多信道机会访问研究](https://arxiv.org/abs/0811.0637)就处理反复ON/OFF与受限感知。因此不能把此反例或标准Bellman计算当首创。

## 两步最优不保证整个截止期内最优

全上线、容量1，价值[3,2,3]，截止期[3,1,3]。两步目标选择第一条，价值6；先做第二条的两步值只有5。然而三步可先做第二条、再做第一和第三条，总价值8；第一条先做会让第二条过期，最多6。反例保存在 diagnostics.json。

这解释了为什么不能仅通过扩大短视方法之间的差异来论证结构优势，必须检查覆盖可见截止期的基线。R2B 的 unpriced_horizon8 与 priced_horizon8 做了这一检查，但它们仍不处理未知未来到达，均不是全局最优oracle。

## 有限时域容量价格对照的边界

对固定可见队列、独立的拟合状态模型、H槽剩余时域，令 `V_i(lambda)` 为目的地i在每次尝试支付lambda后的单目的地最优期望价值。任一满足每槽最多K次尝试的联合策略均满足

`E[completed value] <= lambda*K*H + sum_i V_i(lambda)`, 对任意 `lambda>=0`。

理由：从每次尝试收益扣除lambda后，联合策略在每个目的地的贡献不超过允许其独占资源的单目的地最优值；再加回的总尝试成本最多lambda*K*H。代码选预先固定非负价格网格中最小的上界，并按该价格下“立即尝试－等待”的动作差选K个目的地。上界有效不意味着该排序达到上界，也不证明indexability；故它不是经过证明的Whittle指数策略。

单元测试在独立实现的极小联合POMDP中核对上界，验证模型假设内的性质。真实轨迹的相关故障、错误转移率以及未来到达会破坏把这个上界当真实世界保证的解释。
